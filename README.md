# Cybersecurity Learning Roadmap and Portfolio

This repository is a **comprehensive cybersecurity learning roadmap and portfolio**.
It documents my journey from core IT fundamentals all the way to advanced
offensive and defensive security operations.

Each topic is documented as a Markdown note structured around three sections:

1. **Summary (Theory)** - concept overview, definitions, and key ideas.
2. **Commands (Cheatsheet)** - tools, commands, and useful one-liners.
3. **Lab Output (Proof)** - hands-on results, screenshots, and findings.
